🇹🇼 Taipei Couples Escape (Aug 20-24, 2026)

A beautiful, responsive, and interactive 5-day itinerary web application designed for a couple's getaway to Taipei, Taiwan.

✨ Features

Interactive Smart Map: Built with Leaflet.js, featuring custom icons and auto-panning that syncs directly with the itinerary.

Dynamic Image Fetching: Automatically pulls real, high-quality images from the Wikipedia API for every location to prevent broken links.

Google Maps Integration: One-click routing and transit timings directly from the itinerary cards (MRT, Uber, Walking, Trains).

Traveler Intel: Includes a "Hidden Costs Audit" (plastic bag fees, cafe minimums) and a "Smart Local Apps" guide.

Fully Responsive App Feel: Optimized with dynamic viewports (dvh) to look and feel exactly like a native app on mobile, while providing a gorgeous split-screen experience on desktop.

🛠️ Tech Stack

HTML5 & Vanilla JavaScript (No build steps required)

Tailwind CSS (Via CDN for rapid, responsive UI styling)

Leaflet.js (Open-source interactive mapping)

FontAwesome (Vector iconography)

📂 Project Structure

index.html - The complete, single-file application. Contains all markup, styling, map logic, and itinerary data.

README.md - Project documentation.

💻 How to Run Locally

Because this is a completely self-contained, client-side application, you don't need a server or node modules to run it.

Clone this repository:

git clone https://github.com/doesdesignwork/Taipei-Couples-Escape.git


Simply double-click the index.html file to open it in any modern web browser (Chrome, Safari, Firefox, Edge).
